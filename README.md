## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 첫 화면 (소개, 프로젝트 갤러리, 수상, 활동, 기술) |
| `projects/` | 프로젝트별 상세 페이지 |
| `assets/` | 플레이 영상, 썸네일, 스크린샷 |
| `notion.css` | 사이트 스타일 |
| `v1/` | 이전 디자인 |

각 프로젝트의 코드는 상세 페이지에 연결된 GitHub 저장소에서 볼 수 있습니다.
