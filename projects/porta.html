플레이 피드백에서 “모바일로 만들어 출시해도 좋겠다”는 평을 받았습니다.

개발

  • Q를 누르면 0.2초 동안만 패링 판정이 열리는 방식으로 패링을 만들었습니다.
  • 패링 중에 까마귀의 화살이 닿으면 쏜 까마귀에게 되돌려 보내고, 닌자의 표창은 반대 방향으로 튕겨 냅니다. 튕겨 낸 표창에 맞은 닌자는 데미지와 함께 경직됩니다.
  • 성공 판정은 투사체 쪽에서 내리고 플레이어의 OnParrySuccess()를 호출하게 나눠, 패링에 성공했을 때만 이펙트와 소리가 나게 했습니다.
  • 캐릭터 구동과 애니메이션, HP 4칸과 HP바 연동, 사망 후 부활을 구현했습니다.
  • 찌르기·파워 공격은 공격 지점 주변 범위 안의 적에게 데미지를 줍니다.
// PlayerController2D
// Q: 0.2초 동안만 패링 판정
void StartParryWindow()
{
    isParrying = true;
    parryEndTime = Time.time + parryDuration;
}

// ArrowProjectile: 플레이어에 닿았을 때
if (player.IsParrying)
{
    // 성공할 때만 이펙트·사운드
    player.OnParrySuccess();
    // 쏜 까마귀에게 되돌려 보냄
    ReflectBackToOwner();
}
else
{
    player.HitByProjectile(damageToPlayer);
}

사운드

유료 사운드 에셋을 살 수 없는 상황이어서, 적은 소리로 많은 동작을 채우는 구조부터 만들었습니다.

  • 플레이어 사운드를 관리하는 PlayerSoundManager 스크립트를 직접 작성했습니다.
  • 걷기, 구르기, 점프, 공격 4종, 찌르기, 패링, 피격, 사망 등 동작 15가지의 소리 칸을 나눴습니다.
  • 걷기 소리는 별도 AudioSource로 분리해 움직이는 동안에만 반복 재생되게 했습니다.
  • 게임의 핵심 동작인 패링 소리를 시작 화면 연출에도 넣었습니다.
// 걷기 전용 소스: 움직이는 동안만 루프
walkSource = gameObject.AddComponent<AudioSource>();
walkSource.playOnAwake = false;
walkSource.loop = true;
walkSource.spatialBlend = 0;  // 2D

public void PlayParry() => PlayClip(parryClip, 1f);
